# ⚠️ Codex/GitHub 연결 전 — 비밀키 제거 체크리스트 (필수·최우선)

**절대 원칙: 아래 파일을 리포에 올리거나 Codex에 노출하기 전에 반드시 제거·차단한다.** 하나라도 새면 실계좌(KIS)·API가 위험해진다.

## 1) 실제 키가 든 파일 (루트에서 발견 — 제거/차단 대상)

| 파일 | 내용(추정) | 조치 |
|---|---|---|
| `.kis_key` / `.kis_token` | 한국투자증권 실계좌 API 키·토큰 | **최우선 차단** |
| `.dart_key` | DART 오픈API 키 | 차단 |
| `ecos_key.txt` | 한국은행 ECOS 키 | 차단 |
| `krx_authkey.txt` | KRX 오픈API 키 | 차단 |
| `jq_kakao_token.json` · `jq_kakao_config.txt` · `jq_kakao_auth_log.txt` · `jq_kakao_log.txt` | 카카오 토큰·인증로그 | 차단 |
| `naver_api.json` | 네이버 API | 차단 |
| `재무_APIKEY.txt` (강화키트) | 재무 API 키 | 차단 |

**안전(올려도 됨):** `.kis_key.example` · `진우_KIS키.json.template` — 예시/템플릿이라 실제 키 없음. 단, 열어서 실제 값이 안 들어갔는지 눈으로 확인.

## 2) `.gitignore` 를 리포 루트에 두기 (동봉 파일 사용)

`감사\.gitignore` 를 진우퀀트 루트에 복사하면 위 키 파일 + 로그 + 대용량 데이터가 git에서 제외된다. **git init 전에** 두는 게 안전.

## 3) 코드에 하드코딩된 키가 없는지 스캔 (PC에서)

PowerShell에서 루트에서:

```
Select-String -Path *.py,강화키트\*.py -Pattern "appkey|appsecret|secret|token|authkey|api_key|APIKEY|password|-----BEGIN" -CaseSensitive:$false | Select-String -NotMatch "os.environ|getenv|input\(|example|template|\.json\.template"
```

→ 걸리는 게 있으면 그 줄을 `os.environ`/파일읽기로 바꾼 뒤에 올린다. (대부분 이미 `.kis_key.json` 파일읽기 방식이라 깨끗할 것.)

## 4) 이미 git 히스토리에 커밋했다면

과거 커밋에 키가 남아 있으면 `.gitignore`만으론 부족하다 — 그 커밋 히스토리에서 지워야 하고(예: `git filter-repo`), **해당 키는 즉시 재발급**(KIS/DART/KRX/카카오)하는 게 안전하다.

## 5) 최종 확인 (연결 직전)

- [ ] 위 실제키 파일이 `.gitignore`에 포함됨
- [ ] `git status`에 키 파일이 안 보임(추적 안 됨)
- [ ] 코드 스캔(3번) 결과 하드코딩 키 없음
- [ ] `.kis_key.example`/template에 실제 값 없음 재확인
- [ ] (선택) 걱정되면 감사용으로 **키 파일들을 잠시 폴더 밖으로 옮겨두고** Codex 감사 진행

⚠️ 이 체크리스트를 통과하기 전에는 리포를 Codex/GitHub에 연결하지 말 것.
