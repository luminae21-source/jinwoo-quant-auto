## 1. 백서 — 정리 필요했고, 급했다

| 요약 표 | 최강 팩터 롱숏 **+10.3%** | 검증된 크기는 **+3.4%** (조정본 2015+) |

## 3. §8-3 비용 상수 — SSOT 통일 완료

| 단계 | 결과 |
|---|---|
| 1차 (모듈 상수 `COST`/`TAX`) | 23개 파일 → `_jq_cost(종전값)` |
| 2차 (함수 기본값 `tax`/`slip`) | 14개 파일 · tax 18건 · slip 22건 |
| 3차 (변형 이름 `REF_COST` 등) | 5개 파일 |
| **최종** | **잔존 0** (동결 사양 1건 의도적 제외) |

**종전 상수 분포 → 전부 왕복 0.559%로 통일:**

| 종전 | 건수 | 차이 |
|---|---|---|
| 0.600% | 2 | −0.041%p |
| 0.480% | 2 | +0.079%p |
| 0.300% (다올) | 3 + 함수기본값 22 | +0.259%p |
| 0.235% (v3.7.2) | 13 | +0.324%p |
| 0.200% | 1 | +0.359%p |
| 0.150% | 5 | +0.409%p |

함수 기본값은 스케일링이 아니라 **각 항목을 실측값으로** 바꿨다 —
`tax 0.002 → 0.0015`(실제 증권거래세) · `slip 0.0005 → 0.002045`(CS 실측 편도) = 정확히 0.559%.

**값을 조용히 바꾸지 않았다.** 모든 대입문에 종전 값과 차이를 주석으로 남겼고,
SSOT import 실패 시 종전 값으로 폴백해 단독 실행 가능성을 유지했다.

### ⛔ 의도적 제외 1건 — 이게 중요하다

```
실전준비/재량트랙/discretionary_metrics.py
ROUND_TRIP_COST = 0.0048   ← 바꾸지 않음
```

**forward 트랙의 동결 사양이다.** 트랙 진행 중에 비용 가정을 바꾸면
**1개월차와 2개월차가 다른 자로 재어져 게이트 판정이 무의미해진다.**
사양 변경은 트랙 종료 후 v1.2에서만. 파일에 사유를 명시했고 게이트 G8도 이 경로를 제외한다.

> 일관성보다 **동결이 우선**인 자리가 있다. 전부 통일하는 게 항상 옳은 건 아니다.
