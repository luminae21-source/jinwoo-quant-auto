# 진우퀀트 — 엔트리포인트 지도 (Codex 감사용)

Codex가 어디를 봐야 하는지 안내하는 지도. 리포에 `.py` ~293개가 있어 길잡이 없이는 헤맨다. **감사 관심사별로 어떤 파일을 읽어야 하는지** 아래에 매핑.

## 파이프라인 한눈에 (현행 2세대)

```
데이터수집 → [안전 게이트] → 팩터점수(배당 멀티팩터) → 유니버스(주도주+방어)
   → 2트랙(가치/성장) → 진입(추세위) → 사이징·리스크 → 매도 라우팅 → 추천/집행
```

## 재현 우선순위 (Codex가 돌려볼 것)

1. `py selftest_all.py` — 전 모듈 셀프테스트(합성데이터, 네트워크 불필요) 초록 확인.
2. `py factor_efficacy.py` / `multifactor_screen.py` — 팩터 IC 재현(데이터 필요).
3. `데이터수리\mini_factor_ic_v2_1.py` (+ `mini_kospi_panel_v2_1.csv`) — 자체완결 부분 재현(외부검증 완료본).

## 데이터 파일 (참고 — 대용량, .gitignore로 제외 권장)

- `_월봉종가캐시_KOSPI/KOSDAQ.csv` — 월봉 종가(★미조정 이슈), `종목시총_30년.csv`(37개월 결측), `종목재무_KRX_*.csv`, `종목일봉_30년_*.csv`.
- Codex는 코드 감사가 주목적이므로 데이터는 미니샘플로 충분. 전체 데이터 없이도 "구현 정합성"은 평가 가능.

## 알려진 이슈 (Codex가 재확인/확장할 것)

- ★ 월봉 캐시 **기업행위 미조정**(정수배 점프 3,765건) → raw close를 쓰는 CAGR/롱숏 "크기" 잠정. `데이터수리\ca_flags.csv` 참조.
- 시총 원본 **37개월 결측**(연말) → `mcap_backfill.py`로 대체.
- 자동 역조정기(`ca_adjust.py`)는 그라운드트루스 검증에서 **기각**(과조정) — 프로덕션 금지.
