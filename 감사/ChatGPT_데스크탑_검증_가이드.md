## ChatGPT로 이미 끝낸 것 (데스크탑에서 바로 재사용 가능)

- `강화키트\진우퀀트_GPT검증용.md/.txt/.pdf` — 방법·통계·정직성 7축 감사(붙여넣기/업로드).
- `강화키트\미니샘플\mini_*_v2_1.*` — 팩터 IC(배당 최강) 외부 계산 재현. GPT 독립계산과 소수점 일치까지 확인됨.

**데스크탑 사용법:** ChatGPT 데스크탑 → "프로젝트" 만들고 `강화키트`(또는 검증 파일만 모은 폴더)를 연결 → 위 파일을 첨부하고 감사 지시. 또는 파일 하나 붙여넣기.

## ChatGPT로 아직 검증 안 한 클레임 (다음 미니샘플 후보)

각각 팩터 IC와 같은 방식(실데이터 슬라이스 + 자체완결 스크립트 + v2.1 수준 정직 한계표기)으로 만들 수 있음:

1. **2트랙 조건부** — "배당이 가치·성장 양쪽 다 최강, 성장주선 ROE·성장 유효" (`style_conditional_factor`)
2. **매도 라우팅** — "가치=인내 우위, 성장=트레일이 MDD 도구" (`exit_routing_backtest`)
3. **진입 타이밍** — "추세위(≥MA10) 유효, 전환점(MA200 회복) 무효" (`entry_timing_test`)
4. **EV/FCF** — "정교한 밸류가 단순 배당·E/P를 못 이김" (`ev_fcf_factor_test`)
5. **유니버스 규칙화** — "주도주+50%현금 방어가 스윗스팟(Sharpe 0.85)" (`유니버스_규칙화_검정`)

> 각 미니샘플은 "방향·유의성은 확인 가능 / 크기는 데이터품질(수정주가) 확인 후 / 전체 백테는 별개"의 3층 한계를 동일하게 명시한다.

## 권장 순서

- **Codex 코드감사**를 먼저(구현 정합성) → 코드가 맞다는 확인 위에서 ChatGPT 미니샘플로 **개별 클레임 수치**를 재현하는 게 논리적. 단 둘은 병렬로 돌려도 됨.
- 데이터 품질(수정주가) 확정 전까지, 모든 미니샘플의 "크기" 수치는 잠정.
