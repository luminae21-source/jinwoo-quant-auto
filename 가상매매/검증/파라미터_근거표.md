> **전략의 핵심 파라미터 대부분은 학술적 근거가 없다.** 이것이 이 시스템의 가장 큰 약점이다.
> 근거가 있는 건 "손실을 자르고 이익을 달리게 하라"는 **방향성**뿐이고,
> **구체적 숫자(2.5배, 20일, 2%)는 전부 관행이다.** 백테스트가 이 숫자들의 자리를 벌어줘야 한다.

## 1. ✅ 원문 확인된 근거

### 1-1. 처분효과 (Disposition Effect) — 손절 규칙의 근거

| 항목 | 내용 |
|---|---|
| **출처** | Odean, T. (1998). "Are Investors Reluctant to Realize Their Losses?" *The Journal of Finance*, 53(5), 1775–1798. DOI: 10.1111/0022-1082.00072 |
| **원문 링크** | https://faculty.haas.berkeley.edu/odean/papers%20current%20versions/areinvestorsreluctant.pdf |
| **확인한 수치 (Table I, 원문 직접 확인)** | 전체기간 **PGR = 0.148 / PLR = 0.098** (차이 −0.050) · 12월: PLR 0.128 / PGR 0.108 · 1~11월: PLR 0.094 / PGR 0.152 |
| **검정력** | PGR ≤ PLR 귀무가설 **t > 35로 기각** (1만 계좌, 1987~1993) |
| **검증상태** | ✅ **원문 확인 완료.** 진우님이 기억한 "PGR 14.8% vs PLR 9.8%"는 **정확함.** |
| **시스템 반영** | 사람은 이익을 너무 빨리 실현하고 손실을 너무 오래 붙든다 → **손절을 규칙으로 강제**(재량 금지), **트레일링으로 이익을 달리게** 함. |

> ⚠️ **단, 이 논문은 "2.5×ATR에서 손절하라"고 말하지 않는다.** 손절해야 한다는 *방향*만 뒷받침한다.

## 2. ⚠️ 출처는 있으나 "학술 근거"가 아닌 것

### 2-1. ATR (Average True Range)

| 항목 | 내용 |
|---|---|
| **출처** | J. Welles Wilder, Jr. (1978). *New Concepts in Technical Trading Systems*. Trend Research, Greensboro NC. |
| **링크** | https://en.wikipedia.org/wiki/Average_true_range |
| **성격** | **실무 트레이딩 서적** (peer-review 아님). ATR은 원래 **상품선물**용으로 개발됨. |
| **검증상태** | ⚠️ 지표 정의는 확인됨. **"주식에서 유효하다"는 학술 근거는 확인 못 함.** |
| **엔진 반영** | ATR(14) Wilder 평활 — 정의 그대로 구현. 셀프테스트로 벡터화 버전과 동치 확인. |

### 2-2. 2%룰 (Risk per trade)

| 항목 | 내용 |
|---|---|
| **출처** | Alexander Elder, *Come Into My Trading Room* (실무서) |
| **링크** | https://www.newtraderu.com/2024/01/24/position-sizing-lessons-for-risk-management/ |
| **확인한 사실** | 2%룰은 Elder의 책에서 제시. **Van Tharp는 1%를 권고** (더 보수적). |
| **검증상태** | ❌ **"2%가 최적"이라는 peer-review 근거 없음.** 1%와 2% 중 무엇이 옳은지 학술적 답 없음. |
| **정직한 표기** | **관행/휴리스틱.** 2%는 임의 선택이다. 백테스트에서 민감도를 봐야 한다. |

## 4. ❌ 주장 자체가 출처 미확인 — 사용하지 말 것

### 4-1. "dual MA > triple MA (단순함이 복잡함을 이긴다)"

| 항목 | 내용 |
|---|---|
| **주장** | 지시서에 "연구 결론: 단순함이 복잡함을 이긴다 (dual MA > triple MA)" |
| **검색 결과** | **peer-review 학술 출처를 찾지 못했다.** 검색에 걸린 것은 전부 트레이딩 블로그(TradingView, QuantInsti, QuantifiedStrategies, Medium)다. |
| **게다가 서로 모순됨** | 어떤 블로그는 "triple이 false signal을 더 잘 거른다"고 하고, 다른 곳은 "triple과 dual이 같은 결과"라고 한다. |
| **검증상태** | ❌ **출처 미확인. 이 주장을 설계 근거로 쓰면 안 된다.** |
| **다만** | "타임프레임 분리(상위=방향/하위=타이밍)는 지표 추가가 아니라 축 분리"라는 논리는 **그 자체로 타당**하지만, 이것도 **검증으로 자리를 벌어야** 한다. 백테스트에서 Track S가 Track L 대비, 그리고 상위정합 필터 유무 대비 우위를 못 보이면 **기각**한다. |

### 4-2. "추세추종 승률 35~45%"

| 항목 | 내용 |
|---|---|
| **검색 결과** | 블로그(QuantifiedStrategies)에서 "typical trend-following win rate 30~35%" 언급. **학술 출처 아님.** |
| **검증상태** | ❌ **출처 미확인.** 승률 기대치를 이 숫자에 맞추지 말 것. |
| **대신** | 우리 백테스트의 실측 승률을 쓴다. |

### 4-3. ⚠️ 추가 경고 — 검색 중 발견한 불리한 증거

> 검색 결과 중: *"trend-following works best for commodities... has never found any value in trend strategies related to stocks unless a very long time frame of at least 100 days is used"*
>
> 출처는 블로그라 근거로 채택하지 않지만, **추세추종이 주식에서 잘 안 된다는 반대 주장이 존재한다는 사실 자체는 기록해 둔다.**
> 우리 Track S(20일선)는 "100일 이상 장기 프레임" 조건에 **부합하지 않는다.** → 백테스트에서 특히 엄격하게 볼 것.

## 5. 매도규칙서 v2와의 충돌 (엔진 기본값 결정 근거)

| 항목 | Phase 1 스펙 지시 | 매도규칙서.md v2 (2026-07-12) | 엔진 기본값 |
|---|---|---|---|
| **+1R 절반익절** | "+1R 도달 시 절반 매도" | **삭제됨** | **OFF** (`--half-tp`로 켤 수 있음) |

**매도규칙서 v2의 근거 (진우님 본인 실측 — 외부 논문 아님):**

- 17,948건: 절반익절 有 → 평균승 0.92R / 평균패 −0.93R = 완전 대칭, **기대값 −0.01R (엣지 소멸)**
- 절반익절 除 → 평균승 1.39R / 평균패 −0.73R, 최대 +468R = **비대칭 복원**
- 포트폴리오 sweep (2019~2026, 649거래): 익절목표 +1R → 평균R **−0.012** (승률 44.8%로 최고인데 기대값은 최악) / 무제한 트레일링 → 평균R **+0.122**
- **단조 관계**: 익절을 늦출수록 좋아짐. 예외 없음 (용량-반응 곡선).

> 스펙은 "매도규칙서.md 준수"라고도 지시했다. **두 지시가 충돌한다.**
> 데이터(17,948건 + 단조 sweep)가 절반익절을 명확히 기각하므로 **기본값은 OFF**로 했다.
> 켜고 싶으면 `--half-tp` 한 줄이면 되고, **두 경우 모두 원장에 기록되어 사후 비교가 가능하다.**

> ⚠️ 또한 매도규칙서 v2는 **"무제한 트레일링(+0.122R, CAGR 7.5%)조차 buy&hold(CAGR 21.8%)를 못 이겼다"**고 스스로 적고 있다. 이 사실을 잊지 말 것.

## 6. 이 표를 어떻게 쓸 것인가

1. **❌미검증 파라미터는 백테스트 민감도 격자에서 반드시 확인한다.** 특정 값에서만 좋으면 = 과최적화.
2. **넓은 고원(plateau)이면 robust**, 뾰족한 봉우리면 우연.
3. 채택/기각은 `채택기각_로그.csv`에 기록한다. 근거 없는 값이 백테스트에서도 자리를 못 벌면 **버린다.**
4. **새 파라미터를 추가할 때는 이 표에 먼저 줄을 추가하고 "미확인"이라고 쓴 뒤에 시작한다.**
