내 이론 — 딱 네 줄 (30년·상폐반영·일봉 검증)
  1. 하락장에 싸고(저PBR)+과매도+돌아서는 종목을
  2. 여러 개 분산해서 사고
  3. 승자는 안 자르고 2~3년 안고 가고
  4. 리스크는 스톱이 아니라 소액·분산으로 관리한다

🟢 매수 — 언제·무엇을

  • 하락장(KOSPI < MA200)이 사냥철
  • 저PBR(하위20%) + 이격도<0.85(과매도)
  • + 20일수익>0(돌아서는 것 확인 — 떨어지는 칼 금지)
  • = ◆딥밸류바닥(타점발굴 툴 마커). 검증: 하락장 12개월 시장 2배

🟠 보유 — 승자 미절단

  • 산 건 2~3년 안고 간다(승자는 3년까지 라이딩)
  • −25~30% 평가손은 견딘다(그래야 대박을 먹는다)
  • 익절=강함에 판다: 이격≥1.5 · +100%(2배) · PBR≥1.0
  • 검증: 10종·3년 보유 = CAGR +47%·Sharpe 0.50 (시장 +7%)

◆ 매도 — 진입이 결정

  • 딥밸류 바닥: 타이트 스톱 금지(휩쏘). 분산·인내로 관리
  • 파는 건 적정가치 회귀 or thesis 붕괴 때
  • 넓은 재난백스톱(−40%대)만 선택
  • 모멘텀·돌파 진입은 예외 → 2.5ATR 트레일

🔴 리스크 — 사이징이 생명

  • 한 종목 소액(−50%·상폐돼도 포트 무해)
  • 다분산 10~15종(딥밸류는 넓게 · 1~3종은 파산)
  • ~¼는 실패한다 → 분산으로 희석
  • 스톱으로 못 자르니 처음부터 작게
🧭 지금이 사냥철인가? — 타점발굴 상단의 시장 표시 확인. 하락장이면 ◆딥밸류바닥 후보가 뜬다(그때가 기회). 강세장이면 후보 드묾 = 정상, 무리해서 만들지 말 것.
