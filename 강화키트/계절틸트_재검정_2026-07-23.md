# 계절틸트(Halloween) 재검정 — 충돌 종결 · 2026-07-23

> 목적: 통합전략 v1(2026-07-12)은 계절틸트를 "채택·수익 코어"로, 마스터인덱스·계절틸트_규칙서는 "기각(2026-07-14)"으로 표기 — 이 충돌을 진우님 데이터로 종결한다.
> 방법: 진우님 `jq_seasonality_backtest.py`를 최신 `kospi_index_daily.csv`(1995-05~2026-07, 374개월)로 재실행 + 30년 종목패널 재검정 대조. 투자자문 아님·책임 본인.

## 1. 두 검정이 엇갈린다 (그래서 충돌이 생겼다)

| 검정 | 데이터 | 결과 |
|---|---|---|
| **지수 검정** (`jq_seasonality_backtest.py`, 재실행) | KOSPI 지수 374개월(1995~2026) | **채택후보** — 게이트 전부 통과 |
| **30년 종목패널 재검정** (2026-07-14, 문서) | 5,051종목·상폐포함·1996~2026 | **기각** — 이상치 의존 |

### 1-1. 지수 검정 재실행 결과 (오늘)
- 고전 Halloween(11~4월 100% / 5~10월 현금): **CAGR 11.57% vs buy&hold 8.70%, Sharpe 0.623 vs 0.433, MDD −29.3% vs −68.4%** → 수익·Sharpe·MDD 게이트 전부 통과.
- 틸트 50%(11~4월 100% / 5~10월 50%): "**채택후보 — buy&hold도 이기고, 정적 동일노출도 이김**".
- 죽여보기: 반년 차이 t=2.5(21/30승), **위기(97·98·08) 제외 시 t=1.77**, **발표후(2003~) t=1.50**.

### 1-2. 30년 종목패널 재검정 (기각의 근거)
- **결정타: 89개월 중 6개월만 빼면 효과 소멸** → 강건성 관문 (B) 이상치 제거에서 탈락.
- McLean & Pontiff(2016): 공개된 아노말리는 발표 후 수익 −58%.

## 2. 판정 — 기각 유지 (충돌 종결)

**계절틸트는 기각을 유지한다.** 이유:

1. **더 엄격한 검정이 우선한다.** 지수 검정은 통과하지만, 종목패널의 이상치 제거(6개월)에서 소멸한다. 프로젝트 규율(관문 C·B는 협상 대상 아님)상 **강건성 실패 = 기각**이 원칙이다.
2. **현대 구간 검정력 부족.** 지수 검정도 post-2003 t=1.50, 위기제외 t=1.77로 통계적으로 약하다. 효과가 소수 위기·소수 월에 얹혀 있다.
3. **프로젝트 자신의 선례와 정합.** ②월초강세(IN t=5.49 → OOS 전멸)와 같은 패턴 — "IN에서 예뻤는데 더 좋은 데이터/더 엄격한 컷에서 죽었다."
4. **2026-07-23 안 D(무코어) 확정과 정합.** 재량 라인에 검증 미통과 규칙을 코어로 세우면 그게 data snooping이다.
