# 진우퀀트 — GPT 검증용 단일 파일 (자체완결)

**이 파일 하나면 됩니다.** 두 가지 방법 중 아무거나:
- **방법 A (붙여넣기):** 이 파일 전체를 복사해 ChatGPT 대화창에 그대로 붙여넣고 보내기.
- **방법 B (업로드):** ChatGPT에 이 파일(.pdf 또는 .txt)을 업로드하고 "첨부한 파일을 감사해줘"라고 보내기.

지시문이 **맨 위(【감사 지시문】)** 에 있으므로, GPT는 파일을 읽자마자 무엇을 할지 압니다. 아래 【근거 자료】는 감사 대상 데이터입니다.

> ⚠️ **감사의 성격.** GPT는 원본 데이터·코드를 실행할 수 없습니다. 따라서 이 검증은 **"서술된 방법론·수치의 내적 정합성·통계적 타당성·정직성에 대한 동료평가(red-team)"**이며, 백테스트의 독립 재현이 아닙니다. 재현은 별도로 코드·데이터를 공유해야 합니다.
> ⚠️ 정보·검증용. 미래·수익 보장 아님. 투자자문 아님·최종 책임 본인.

# 【근거 자료】 — 감사 대상

## §1. 프로젝트 개요

**진우퀀트** = 한국주식 개인 퀀트 시스템. 현행(2세대) 파이프라인:

`① 주도주 top30 동적 유니버스 → ② 가치/성장 2트랙 분리 → ③ 배당 중심 멀티팩터 점수 → ④ 추세 레짐 진입 → ⑤ 트랙별 매도·사이징`

- **개발 주체:** 개인 1인 (+ AI 협업).
- **데이터:** 1996~2026, **상폐 포함(생존편향 제거)** KOSPI+KOSDAQ 약 5,000종목 월봉 패널 + PIT 시총(64.5만 행) + KRX 재무(배당·PER·PBR·성장).
- **비용 모델:** 다올투자증권 기준(위탁수수료 0 + 매도 증권거래세 0.20% + 슬리피지).
- **자동화:** 매주 월 추천·카톡, 매월 6일 재검증, 허브(SSOT)·이력 DB. 2026-07-26 fail-safe 안전 게이트·데이터 헬스체크·스냅샷/롤백·PIT 공시시차 강제·전 모듈 셀프테스트 집계 추가.

|---|---|---|---|---|---|
| 배당수익률 | +0.0487 | 5.9 | +10.3% | 0.68 | 58% |
| 가치 B/P | +0.0372 | 3.1 | +10.5% | 0.48 | 55% |
| 가치 E/P | +0.0303 | 2.9 | +8.8% | 0.48 | 55% |
| 성장 EPS성장 | +0.0199 | 2.7 | +8.1% | 0.62 | 58% |

**2-2. 스타일 조건부** (저PBR 가치 / 고PBR 성장, 약 247개월)
- 배당은 **양쪽 다 최강**: 가치주 t=4.8, 성장주 t=4.3.
- 성장주: ROE t=2.8, EPS성장 t=2.3 유효 / E/P 약함(t=1.3). 가치주: E/P t=3.2 유효.

**2-3. 진입 타이밍** (24년)
- **추세위(≥MA10) 유효**: 가치 6개월 +11.9%(승률 58%), 성장 +5.3%.
- **전환점(MA200 회복·골든크로스) 무효**(지연): 가치 8.8%로 오히려 낮음.

**2-4. 매도 라우팅** (24년)
- **가치 = 인내 우위**: 스톱없음 CAGR 13.4%·MDD −51% vs 라우팅 12.4%·−67%.
- **성장 = 트레일이 MDD 도구**: 스톱없음 MDD −72% → 트레일 −56%.

**2-5. EV/FCF** (정교한 밸류, 5년/57개월)
- E/P(IC 0.066·t2.7·롱숏 17.3%)·배당(0.066·t3.0)·B/P(0.058) > EV/EBIT(0.046·t2.1) > EV/EBITDA(0.045·t1.7) > **FCF(0.019·t1.1·롱숏 −7%)**. → "정교함 ≠ 알파".

**2-6. 유니버스 규칙화** (30년, 다올 비용후, EW·월리밸, 사전등록 게이트)

**2-7. 정직한 자기정정 (핵심)**
- 초기 v3.7.2 백테 **CAGR 73%·Sharpe 2.88**은 손으로 고른 18종·특정구간 **힌드사이트**로 판정 → 같은 로직 30년 기계재현 **17.7%·Sharpe 0.83**을 정직한 forward로 채택.
- 초기 핵심이던 **종목선택용 횡단면 모멘텀은 넓은 패널서 약함(t=0.7)** → 배당·가치로 전환(한국은 개별주 횡단면 모멘텀이 약한 시장으로 문헌과 일치). **단 "폐기"가 아니라 "역할 재배치"** — 시계열 추세(MA200 방어·MA10 진입)는 타이밍·방어용으로 유지.
- 계절순환(횡단면): 깨끗한 30년서 **0/4**(gross +4.7%였으나 회전세금이 신호 초과). 결론은 "계절성 부재"가 아니라 **"이 회전율에선 매매 불가"** — 저회전(연 1~2회 캘린더) 표현은 미검증·재검토 대기.

**2-8. 엔지니어링 건전성** (2026-07-26, 실제 PC 검증)
- **fail-open → fail-safe:** 데이터 실패 시 직전 데이터로 진행·발송하던 구조를, **안전 게이트 통과 때만 발송**으로 전환. STALE이면 발송 차단 + 자기알림.
- **데이터 무결성 자동검사:** 신선도·커버리지·월연속성·이상치·중복·**룩어헤드** → PASS/WARN/FAIL. 실측 최신 2026-07, 미래재무 0건, WARN(이상치 0.9%)로 건전.
- **PIT 공시시차 강제·감사:** 백테용 공시지연(기본 2개월) 강제 + 라이브 감사(재무 2026-06 ≤ 가격 2026-07 = 정상).
- **전 모듈 셀프테스트:** 프로젝트 **93개 모듈 일괄 실행 100% 통과**(실제 PC). 단 이는 "코드 실행+내부 단위검증(합성데이터) 통과"이며 **백테 독립 재현이 아님**.
- **백업/롤백:** 수집 전 핵심 패널 스냅샷 + 롤백.
- (감사 주의: 위는 "시스템이 견고하게 돌고 자기정합적"의 근거이지, 외부 데이터로 §2 수치를 재현했다는 뜻이 아님.)

## §3. 방법론 (엄밀성 감사 대상)

1. **생존편향 제거** — 상폐 종목 포함 30년 패널.
2. **룩어헤드 차단** — 설명변수는 확정월까지만, 예측은 다음달.
3. **사전등록** — 변수·가설·합격선을 결과 보기 전 고정, 사후 튜닝 금지.
4. **4관문** — ① IN p<0.05 ② 이상치 강건 ③ **OOS 봉인구간 부호 유지** ④ 비용(다올) 통과.
5. **다중검정 보정** — 방향가설 |t|≥2.3, 탐색 |t|≥3.0. "통과 0개도 정상 결론".
6. **비용 인식** — 회전율×(매도세+슬리피지) 반영, 다올 무료수수료 특수성 반영.
7. **과최적 자각 지표** — 자체 관찰 "IN·OOS Sharpe 상관 = −0.709"("예쁜 백테일수록 실전 열위")를 기각 규율의 근거로 사용.
8. **채택 판정 = vs MKT + IC** (EW 탐색의 대형주·틸트 아티팩트 방지).
9. **기각의 대칭성(Type-I ↔ Type-II)** — 과최적(가짜 양성)을 막는 규율만큼, 진짜지만 수수한 엣지를 죽이는 **가짜 음성**도 감시. 간발의 기각(1.5≤|t|<2.3)이나 "신호는 있으나 비용·회전율에서만 죽은" 후보는 삭제 않고 재검토 대기로 보존, 더 싼 표현서 재검정.

## §4. 자체 수준 평가 (감사자가 동의/반박할 대상)

**한 줄 결론: 리서치 방법론은 프로 퀀트 리서치급(석사논문~주니어 실무), 개인 퀀트 상위 1~2%. 그러나 실전 트랙레코드가 공백이고 인프라·breadth·집행은 개인·초기급.**

| 영역 | 자체 평가 | 근거 |
|---|---|---|
| 검증 방법론(엄밀성) | A− | 생존편향제거·사전등록·OOS·IC/t·비용·다중검정보정 |
| 정직성·자기정정 | A | 73%→17.7% 정정, 모멘텀 재배치, 0개 통과 수용 |
| 팩터 리서치 | A− | IC/t, 스타일 조건부, EV/FCF 반증, 멀티팩터 합성 |
| 시스템 설계 | B+ | 2트랙·동적 유니버스·매도 라우팅 |
| 자동화·운영 | A− (←B+) | fail-safe 게이트·실패알림·셀프테스트 집계 |
| 데이터 인프라 | A− (←B) | 신선도·룩어헤드 검사 + 백업/롤백 + PIT 강제 |
| 엔지니어링 검증 | B+ | 93모듈 셀프테스트 100%(실행·자기정합), 백테 재현은 별개 |
| **실전 검증(트랙레코드)** | **D** | forward 실현 기록 사실상 0 — 최대 공백 |

**비교 기준:** 개인 대비 상위 1~2%(생존편향제거·사전등록·IC검정·비용인식·힌드사이트 정정을 실제로 하는 개인은 극소수). 학술 대비 표준 툴킷·신규성 낮음 = 견실한 응용. 기관 대비 리서치 규율은 근접, 미달은 인프라·breadth·집행·**라이브 트랙레코드**·팀(=규모·실전이지 엄밀성 아님).

## §5. 알려진 한계·열린 질문 (감사자가 확인·확장할 것)

1. **인과 미확립:** "배당이 왕"은 상관(t=5.9)이지 인과 아님. 배당·E/P·B/P는 분모가 주가 → **밸류 교란** 가능. 직교화 증분IC·이중정렬·스패닝 회귀 미실시. 멀티팩터가 "밸류 3중 베팅"일 위험.
2. **라이브 트랙레코드 0:** 모든 수치가 백테/검증. 실전 기록 미착수.
3. **단일 분석가·단일 자산군:** 한국 롱온리, 1인. 독립 재현 안 됨.
4. **PIT 재무 정밀도:** 라이브 재무월 ≤ 가격월(미래재무 0), 백테 공시지연(2개월) 강제 — 단 정정공시·개별 실제 공시일 단위 정밀도는 월 단위 근사.
5. **국면 의존:** 배당·가치는 금리·레짐 의존 가능(레짐 분할 미실시).
6. **집행 반자동:** KIS API 미구현, 수동 승인.
7. **유니버스 초과 얇음:** 동적 리더십의 대형주 대비 위험조정 초과가 고슬리피지서 소멸(G4).
8. **기각 편향(Type-II) 가능성:** 엄격 게이트+보수 비용모델이 "진짜지만 작은" 엣지를 과기각할 위험. 대칭 점검(§3-9) 도입했으나 저회전 표현 재검정은 다수 미실시.

*수치는 백테·검증값이며 실현손익이 아님. 라이브 수치의 진실은 별도 운영 허브가 SSOT. 투자자문 아님·최종 판단·책임 본인.*
