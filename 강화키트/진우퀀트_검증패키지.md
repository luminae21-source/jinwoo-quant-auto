# 진우퀀트 — 외부 검증 패키지 (ChatGPT 등 제3자 감사용)

> **목적:** 이 문서 하나로, 데이터에 접근할 수 없는 제3자(ChatGPT 등)가 진우퀀트 개발 자료의 **방법론·통계·정직성·수준**을 독립적으로 감사할 수 있게 한다.
> **사용법(진우님):** 이 문서 전체를 복사해 ChatGPT에 붙여넣고, 맨 아래 "§6 검증 요청 프롬프트"를 함께 보내면 된다.
> **중요한 한계:** ChatGPT는 원본 데이터·코드를 실행할 수 없다. 따라서 이 검증은 **"서술된 방법론·수치의 내적 정합성·통계적 타당성·정직성에 대한 동료평가"**이지, 백테스트의 독립 재현이 아니다. 재현 검증은 별도(코드·데이터 공유)로 해야 한다.
> ⚠️ 정보·검증용. 미래·수익 보장 아님. 투자자문 아님·책임 본인.

## §1. 프로젝트 개요 (검증 대상)

**진우퀀트** = 한국주식 개인 퀀트 시스템. 현행(2세대) 파이프라인:

`① 주도주 top30 동적 유니버스 → ② 가치/성장 2트랙 분리 → ③ 배당 중심 멀티팩터 점수 → ④ 추세 레짐 진입 → ⑤ 트랙별 매도·사이징`

- **개발 주체:** 개인 1인 (+ AI 협업).
- **데이터:** 1996~2026, **상폐 포함(생존편향 제거)** KOSPI+KOSDAQ 약 5,000종목 월봉 패널 + PIT 시총(64.5만 행) + KRX 재무(배당·PER·PBR·성장).
- **비용 모델:** 다올투자증권 기준(위탁수수료 0 + 매도 증권거래세 0.20% + 슬리피지).
- **자동화:** 매주 월 추천·카톡, 매월 6일 재검증, 허브(SSOT)·이력 DB(jq_history.db). **(2026-07-26)** fail-safe 안전 게이트·데이터 헬스체크·스냅샷/롤백·PIT 공시시차 강제·전 모듈 셀프테스트 집계 추가.

### 2-2. 스타일 조건부 (저PBR 가치 / 고PBR 성장, 약 247개월)
- 배당은 **양쪽 다 최강**: 가치주 t=4.8, 성장주 t=4.3.

- 가치주: E/P t=3.2 유효.

### 2-3. 진입 타이밍 (24년)
- **추세위(≥MA10) 유효**: 가치 6개월 +11.9%(승률 58%), 성장 +5.3%.
- **전환점(MA200 회복·골든크로스) 무효**(지연): 가치 8.8%로 오히려 낮음.

### 2-4. 매도 라우팅 (24년)
- **가치 = 인내 우위**: 스톱없음 CAGR 13.4%·MDD −51% vs 라우팅 12.4%·−67%.
- **성장 = 트레일이 MDD 도구**: 스톱없음 MDD −72% → 트레일 −56%.

### 2-5. EV/FCF (정교한 밸류, 5년/57개월)
- E/P(IC 0.066·t2.7·롱숏 17.3%)·배당(0.066·t3.0)·B/P(0.058) > EV/EBIT(0.046·t2.1) > EV/EBITDA(0.045·t1.7) > **FCF(0.019·t1.1·롱숏 −7%)**. → "정교함 ≠ 알파".

### 2-6. 유니버스 규칙화 (30년, 다올 비용후, EW·월리밸, 사전등록 게이트)

| 유니버스·방어 | 순 CAGR | Sharpe | MDD | 게이트 |
|---|---|---|---|---|
| KOSPI 벤치 | 6.9% | 0.37 | −63.3% | — |
| 고정18(레거시 재현) | 17.7% | 0.83 | −44.9% | 기준 |
| 주도주 top30 무방어 | 21.7% | 0.78 | −64.3% | — |
| 주도주+50%현금 방어 | 20.1% | **0.85** | −44.2% | **3/4 조건부** |

- 판정 3/4: 낙폭제어는 전 비용수준 강건(−64%→−44%), 단 "재현가능 대형주 대비 위험조정 초과"가 고슬리피지서 얇음(G4 미달). 리더셋 **연 42% 교체**.

### 2-7. 정직한 자기정정 (핵심)
- 초기 v3.7.2 백테 **CAGR 73%·Sharpe 2.88**은 손으로 고른 18종·특정구간 **힌드사이트**로 판정 → 같은 로직 30년 기계재현 **17.7%·Sharpe 0.83**을 정직한 forward로 채택.
- 초기 핵심이던 **종목선택용 횡단면 모멘텀은 넓은 패널서 약함(t=0.7)** 확인 → 배당·가치로 전환. (한국은 개별주 횡단면 모멘텀이 약한 시장으로 문헌과 일치.) **단 "폐기"가 아니라 "역할 재배치"** — 시계열 추세(MA200 방어·MA10 진입)는 타이밍·방어용으로 유지.
- 계절순환(횡단면): 깨끗한 30년서 **0/4**(gross +4.7%였으나 회전세금이 신호 초과). **결론은 "계절성 부재"가 아니라 "이 회전율에선 매매 불가"** — 저회전(연 1~2회 캘린더) 표현은 미검증으로 재검토 대기(무기후보 등록부).

### 2-8. 엔지니어링 건전성 (2026-07-26, 실제 PC 검증)
- **fail-open → fail-safe:** 파이프라인이 데이터 실패 시 직전 데이터로 진행·발송하던 구조를, **안전 게이트(preflight) 통과 때만 발송**하도록 전환. STALE이면 카톡 차단 + 자기알림.
- **데이터 무결성 자동검사:** 신선도·커버리지·월연속성·이상치·중복·**룩어헤드(재무월>가격월)** → PASS/WARN/FAIL. 실측: 최신 2026-07, 미래재무 0건, WARN(이상치 0.9%)로 건전.
- **PIT 공시시차 강제·감사:** 백테용 `apply_disclosure_lag`/`as_of`(기본 2개월) + 라이브 감사(재무 2026-06 ≤ 가격 2026-07, 시차 1개월 = 정상). 셀프테스트 3/3.
- **전 모듈 셀프테스트:** 프로젝트 **93개 모듈을 일괄 실행해 100% 통과**(실제 PC). 단, 이는 "코드가 실행되고 각 모듈의 내부 단위검증(합성데이터)이 통과"를 의미하며 **백테의 독립 재현이 아님**.
- **데이터 백업/롤백:** 수집 전 핵심 패널 스냅샷 + 롤백(덮어쓰기 복구).

> **감사 주의:** 위는 "시스템이 견고하게 돌고 자기정합적이다"의 근거이지, 외부 데이터로 백테 수치(§2)를 재현했다는 뜻이 아니다. §2 수치의 독립 재현은 여전히 코드·데이터 공유가 필요하다.

## §3. 방법론 (엄밀성 감사 대상)

1. **생존편향 제거** — 상폐 종목 포함 30년 패널.
2. **룩어헤드 차단** — 설명변수는 확정월까지만, 예측은 다음달.
3. **사전등록(pre-registration)** — 변수·가설·합격선을 결과 보기 전 고정, 사후 튜닝 금지.
4. **4관문** — ① IN p<0.05 ② 이상치 강건 ③ **OOS 봉인구간 부호 유지** ④ 비용(다올) 통과.
5. **다중검정 보정** — 방향가설 |t|≥2.3, 탐색 |t|≥3.0. "통과 0개도 정상 결론".
6. **비용 인식** — 회전율×(매도세+슬리피지) 반영, 다올 무료수수료 특수성 반영.
7. **과최적 자각 지표** — 자체 관찰 "IN·OOS Sharpe 상관 = −0.709"("예쁜 백테일수록 실전 열위")를 기각 규율의 근거로 사용.
8. **채택 판정 = vs MKT + IC** (EW 탐색의 대형주·틸트 아티팩트 방지).
9. **기각의 대칭성(Type-I ↔ Type-II)** — 과최적(가짜 양성)을 막는 규율이 강한 만큼, 진짜지만 수수한 엣지를 죽이는 **가짜 음성**도 감시한다. 간발의 기각(방향가설 1.5≤|t|<2.3)이나 "신호는 있으나 비용·회전율에서만 죽은" 후보는 삭제하지 않고 **재검토 대기(무기후보 등록부)**로 보존해 더 싼 표현에서 재검정한다.

## §4. 자체 수준 평가 (감사자가 동의/반박할 대상)

**한 줄 결론: 리서치 방법론은 프로 퀀트 리서치급(석사논문~주니어 실무 수준), 개인 퀀트 중 상위 1~2%. 그러나 실전 트랙레코드가 공백이고 인프라·breadth·집행은 개인·초기급.**

| 영역 | 자체 평가 | 근거 |
|---|---|---|
| 검증 방법론(엄밀성) | A− | 생존편향제거·사전등록·OOS·IC/t·비용·다중검정보정 |
| 정직성·자기정정 | A | 73%→17.7% 힌드사이트 정정, 모멘텀 폐기, 0개 통과 수용 |
| 팩터 리서치 | A− | IC/t-stat, 스타일 조건부, EV/FCF 반증, 멀티팩터 합성 |
| 시스템 설계 | B+ | 2트랙·동적 유니버스·매도 라우팅, 논리 일관 |
| 자동화·운영 | B+ → **A−** | fail-safe 게이트·실패알림·셀프테스트 집계로 "조용한 실패" 제거 |
| 데이터 인프라 | B → **A−** | 신선도·룩어헤드 검사 + 백업/롤백 + PIT 공시시차 강제 |
| 엔지니어링 검증(코드 건전성) | B+ | 93개 모듈 셀프테스트 100% 통과(실행·자기정합). 단 백테 독립재현은 별개 |
| **실전 검증(트랙레코드)** | **D** | forward 실현 기록 사실상 0 — 최대 공백 |

**비교 기준:**
- **개인 투자자 대비:** 상위 1~2%. 생존편향제거·사전등록·IC검정·비용인식·힌드사이트 정정을 실제로 하는 개인은 극소수.
- **학술 대비:** 방법(IC·OOS·사전등록·factor zoo)은 표준 학술 툴킷. 신규성은 낮음(배당·가치 in 한국은 기존 문헌). = 견실한 응용 수준.
- **기관 퀀트 대비:** 리서치 규율은 진지한 시스템 운용사의 프로세스에 근접. 미달은 데이터 인프라·전략 breadth·집행·리스크시스템·**라이브 트랙레코드**·팀 — 엄밀성이 아니라 규모·실전.

## §5. 알려진 한계·열린 질문 (감사자가 확인·확장할 것)

1. **인과 미확립:** "배당이 왕"은 상관(IC t=5.9)이지 인과 아님. 배당·E/P·B/P는 분모가 주가 → **밸류 교란** 가능. 직교화 증분 IC·이중정렬·스패닝 회귀 미실시(별도 검정 예정). 멀티팩터 합성이 "밸류 3중 베팅"일 위험.
2. **라이브 트랙레코드 0:** 모든 수치가 백테/검증. 실전 페이퍼·소액 기록 미착수.
3. **단일 분석가·단일 자산군:** 한국주식 롱온리, 1인. 코드·검증의 독립 재현 안 됨.
4. **PIT 재무 정밀도:** 라이브 감사상 재무월 ≤ 가격월(미래재무 0), 백테용 공시시차 강제(기본 2개월) 도입 — 다만 **정정공시(restatement)·개별 종목 실제 공시일** 단위 정밀도는 미반영(월 단위 근사). 감사 질문 유효.
5. **국면 의존:** 배당·가치는 금리·레짐 의존 가능(레짐 분할 미실시).
6. **집행 반자동:** KIS API 미구현, 수동 승인.
7. **유니버스 초과 얇음:** 동적 리더십의 대형주 대비 위험조정 초과가 고슬리피지서 소멸(G4).
8. **기각 편향(Type-II) 가능성:** 엄격한 게이트+보수적 비용모델이 "진짜지만 작은" 엣지를 과도하게 기각할 위험. 대칭 점검(§3-9)을 도입했으나, 저회전 표현 재검정은 아직 다수 미실시(예: 계절성 캘린더 오버레이). 감사자가 확인·확장할 지점.

## §6. ChatGPT 검증 요청 프롬프트 (이 아래를 함께 붙여넣기)

```
너는 시스템 트레이딩/계량금융을 감사하는 냉정한 동료평가자다. 아래 "진우퀀트 외부 검증 패키지"를
읽고, 칭찬이 아니라 결함을 찾는 적대적(red-team) 관점으로 검증하라. 데이터·코드는 없으니
"서술된 방법론·수치의 내적 정합성·통계적 타당성·정직성"만 평가하고, 재현이 필요한 부분은 명시하라.

다음 7개 축으로 각각 판정(✅타당/⚠️의심/❌결함)과 근거를 달라:

A. 통계적 타당성 — IC t값 해석이 맞나? 다중검정 보정(|t|≥2.3/3.0)이 팩터 7개 검정에 충분한가?
```
