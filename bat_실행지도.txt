# 진우퀀트 bat 실행 지도 (2026-08-07 정리)

손으로 실행할 일은 대부분 `진우퀀트_실행메뉴.bat` 하나면 됩니다.
(기존 bat은 그대로 두고 메뉴에서 호출만 합니다)

## 자주 쓰는 진입점 (메뉴에 포함)
- 일일_올인원_실행.bat : 분류→이중바닥→거래대금→뷰생성
- 진우_자동갱신_파이프라인.bat : 일봉 증분수집→발굴툴 전체 재생성
- jq_daily_update.bat : KOSPI 일봉 수집+정합성 검증
- 시장브리핑_실행.bat / 강화키트\추천_실행.bat / 강화키트\허브_실행.bat
- jq_weekly_run.bat (주간) / 강화키트\유니버스_월초생성.bat (월초)
- 진우퀀트_월간갱신.bat (월간) / 강화키트\전체갱신_실행.bat (풀 리빌드)

## 직접 실행하지 않아도 되는 것들
- `*_자동.bat` : 작업 스케줄러가 부르는 무인 실행용 (pause 없음)
- `*_등록.bat`, `*_register*.bat`, `*스케줄등록.bat`, 예약작업_재등록_전체.bat
  : Windows 작업 스케줄러에 등록하는 1회성 스크립트 (관리자 권한 필요한 것 있음)
- 나머지 `*_실행.bat` : 개별 모듈 단독 실행용 (필요할 때만)

## 클라우드(클로드) 예약 작업 - 2026-08-07 통합 후 3개
1. 일일: 진행현황 대시보드 자동갱신 (매일 아침)
2. 주간: 백서 갱신 - 매달 첫 회는 자동으로 심층 개정 (월요일 아침 KST)
3. 월초: 통합 리마인더 (forward 리밸런싱 + 유니버스 갱신, 매월 1일)
