## 확인 방법 — 정적 분석의 한계

정적 패턴만으로는 최종 판정이 불가능하다. 결정적 검사는 **실행 기반**이다:

```python
# 선택 변수에 shift(1)을 넣고 다시 돌린다
M_orig = mcap.pivot_table(...)
M_lag  = M_orig.shift(1)
# 두 결과의 CAGR 차이가 3%p 이상이면 → 그 변수는 미래 정보를 담고 있다
```

이 검사는 어떤 선택 변수에도 적용된다(시총·거래대금·재무·모멘텀).
**self-test에 넣으면 이 종류 버그는 재발하지 않는다.**
