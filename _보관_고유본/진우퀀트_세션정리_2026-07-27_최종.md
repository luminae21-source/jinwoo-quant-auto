## 2. 🚨 핵심 발견 — 시총 룩어헤드

`종목시총_30년.csv`의 date가 **월말 스냅샷**인데, 강화키트 30년 백테는
이 시총으로 **같은 달의 수익률**을 계산한다. 오른 종목이 사후에 큰 시총을 가지므로
**자동으로 승자를 선택**하게 된다.

```python
# 유니버스_리더십로테이션.py / 유니버스_규칙화_검정.py
rets = px.pct_change()                    # 당월 수익 (t-1 → t)
mc   = mcap.loc[t]                        # 당월말 시총  🚨
mom  = px.iloc[i-13:i-1]                  # 모멘텀은 정상 시차 ✅
```

**전월말 시총(`shift(1)`)으로 교정하면:**

| 전략 | 백서 | 교정 후 | 차이 |
|---|---|---|---|
| TOP30_고정 (베이스라인) | 19.8% | **4.9%** | −14.9%p |
| 동적 리더십 무방어 | 21.7% | **7.8%** | −13.9%p |
| 전종목 시총가중 (KOSPI 프록시) | 19.3% | **4.4%** | −14.9%p |
| KOSPI (백서 기재) | 6.9% | — | — |

교정 후 시총가중 프록시 4.4%가 KOSPI 6.9%와 같은 자리에 선다.
**"TOP30이 KOSPI를 연 12.9%p 이긴다"는 미스터리가 룩어헤드였다.**

재현 충실도: lag=0에서 내 재현값(20.9%/22.6%)이 백서값(19.8%/21.7%)과 **1%p 이내** 일치.

**왜 못 봤나:** 모멘텀 창은 시차 처리가 정확하다(`i-13:i-1`). 코드가 룩어헤드를
의식하는 것처럼 보여 시총 pool 축은 검토에서 빠졌다. `--self-test 6/6`도 이 축을 검사 안 한다.

**남은 것:** 교정 후에도 동적 리더십 7.8% > 베이스라인 4.9% (**+2.9%p**).
방향성은 살아 있다. 단 MDD가 −48% → **−73.6%**로 악화.

## 3. ✅ 살아남은 것 — mini_*.py는 정상

```python
ret = px.pct_change().shift(-1)   # t월 보유 → t+1 수익  ✅
```

네 스크립트(`mini_universe_adj` · `mini_leader_rule` · `mini_pbo_dsr` · `mini_factor_adj`)
모두 forward 수익률을 쓴다. **오전 세션 결과는 이 축으로 무사.**

추가 검증도 전부 통과:

| 검사 | 결과 |
|---|---|
| 시총 데이터 PIT | ✅ 1996-01 top30 = 한국전력·삼성전자·포항제철·한국이동통신 |
| 시총 상폐 포함 | ✅ 5,042 중 2,275개(45.1%) 소멸 |
| 가격캐시 생존편향 | ✅ 소멸률 51.5% (시총파일보다 높음) |
| 스타일패널 생존편향 | ✅ 691종목 중 410개(59.3%) 이탈, 상폐 확인 115건 |
| **재무 PIT 시차** | ✅ roe 변경이 **4~5월 88% 집중** = 연간재무 3월말 공시 후 반영 |
| CSCV 구현 | ✅ combinations(12,6) = **924조합** 정확 |
| 백업 3벌 | ✅ 해시 완전 일치 |

**따라서 유효:** 배당 +3.4% · B/P +6.6% · IC HAC t 4.10/3.34/2.36 · PBO 57.5% · DSR 91.7% · 멀티팩터 8.1%

## 4. 20.1% 판정 — 네 번 바뀐 끝에

| 시점 | 판정 | 근거 |
|---|---|---|
| 오전 세션 | 재현 실패 → 강등 | 다른 규칙·기간으로 검증 |
| 오후 초반 | 검증 불가 | 백서 강등사유 분석 |
| 오후 중반 | **강등 무효** | 원 코드·판정문 확인 (규칙은 명시돼 있었음) |
| **최종** | **무효화 (룩어헤드)** | **원 데이터 직접 재현·교정** |

**20.1%는 쓸 수 없다. 그러나 오전 세션이 든 사유("재현 실패")는 여전히 틀렸다.**
오전의 "재현"은 원 규칙(12-1 모멘텀)이 아니라 **부호가 반대인 가치·배당 z합성**을,
30년이 아닌 11년에, TOP30_고정 EW가 아닌 KOSPI CW 대조군으로 돌린 것이었다.

## 9. 메타 교훈

백서 1.1절이 스스로 적어둔 원칙:
> **"검증된 규칙만 시스템으로 삼는다 — 공식 실데이터, 30년 상폐포함 패널, 룩어헤드 차단."**

**룩어헤드를 차단하겠다고 선언한 문서가, 룩어헤드 때문에 자기 숫자를 잃었다.**
선언이 거짓이었던 게 아니라 **선언을 검사할 도구가 없었다.** 이제 있다.

그리고 오늘 살아남은 것들을 보면 패턴이 보인다 —
**최근에 짠 코드(mini_*)가 예전 코드(강화키트)보다 정확하다.**
`shift(-1)`을 넣었고, 재무 시차를 지켰고, 상폐를 담았다.
검증 실력이 실제로 올라가고 있다는 증거다.

> 오늘 잃은 것: "연 20%"라는 숫자 하나.
> 잃지 않은 것: 팩터 방향성, 검증 방법론, 데이터 인프라, 운영 파이프라인, 그리고 자본.
> **그 숫자는 실전 자금이 들어가기 전에 죽었다.**
