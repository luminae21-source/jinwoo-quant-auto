```

```

**날짜별로 받는다.** 그날 살아있던 종목이 그대로 나온다. 상폐 예정 종목도 포함된다.
각 날짜의 실제 상장 유니버스 = 진짜 point-in-time 패널.

**왜 종목별로 받으면 안 되는가 (v1의 치명적 결함, 2026-07-13 발견)**

→ 상폐된 종목은 조용히 실패하고 넘어간다 → **생존자만 남는다.**
5,217종목 유니버스를 찾아놓고도 데이터는 2,700개만 받는, 최악의 자기기만이 될 뻔했다.

## 3. ★ OOS 분할 — 지금 못 박는다

| 구간 | 기간 | 용도 |
|---|---|---|
| **IN** | **1996 ~ 2012** (17년) | 탐색·추정. 여기만 본다 |
| **OOS** | **2013 ~ 2026** (14년) | **봉인.** 최종 판정 때 딱 한 번 연다 |

- **분할점 2012/2013은 처음 작성 때 그대로다.** 데이터 가용 범위(1995→1996)만 바뀌었다.
  **결과를 보고 바꾼 것이 아니다.**
- OOS는 **한 번만** 연다. 결과가 나쁘다고 분할을 바꾸지 않는다.
- 할로윈 기준: IN 약 16 겨울/여름 쌍, OOS 약 13쌍. **(지금은 전체 7쌍뿐)**

## 4. 검정 방법 (고정)

1. **동일가중(EW) 포트폴리오**로 묶는다. 종목-일 풀링 금지 —
   횡단면 상관 때문에 t값이 뻥튀기된다(오늘 t=−12.24 → 실제 −1.56으로 붕괴한 사고).
2. **월별 대응표본(paired)** 검정. 월을 독립 단위로 본다.
3. **비모수 병행**: Wilcoxon / Mann-Whitney. 이상치에 강건한지 본다.
4. **세그먼트**: 시가총액 3분위 (소·중·대). 대형주는 이미 차익거래로 소진됐을 것.
5. **비용**: 한국 매도세 0.18% + 수수료 + 슬리피지 → 왕복 0.45%(현실) / 0.70%(보수).

## 5. ★ 판정 규칙 — 결과 보기 전에 고정

각 가설은 **네 관문을 모두 통과**해야 채택된다.

| 관문 | 기준 |
|---|---|
| **(A) IN 유의** | IN 구간 p < 0.05 |
| **(B) 이상치 강건** | 최악·최고 각 3개월 제외 후에도 p < 0.10 이고 부호 유지 |
| **(C) OOS 생존** | **OOS 구간 p < 0.05 이고 부호 유지** ← 핵심 관문 |
| **(D) 비용 통과** | 왕복 0.45% 비용 후에도 buy&hold 초과 (또는 **비용 0인 진입필터로만 사용**) |

**판정**
- **4/4 통과** → **채택**
- (A)(B)(C) 통과, (D) 실패 → **진입 필터로만 채택** (비용 0 · 매매 추가 없음)
- **(C) 실패** → **기각.** OOS를 통과 못 하면 그걸로 끝이다. 예외 없다.
- (B) 실패 → **기각** (소수 이상치 의존 = 테일 리스크지 알파가 아님)

**다중검정**: 4개 가설 × 3개 시총분위 = 12개 검정 → **Bonferroni ×12** 병기.
