## 입주 조건 — 네 관문을 다 통과해야 한다

관문은 **데이터를 보기 전에** 정해서 봉인한다. 결과를 보고 바꾸면 그 순간 전부 무의미해진다.

| 관문 | 기준 |
|---|---|
| **(A) IN 유의** | 학습 구간 p < 0.05 |
| **(B) 이상치 강건** | 최악·최고 각 3개월 빼도 p < 0.10, 부호 유지 |
| **(C) OOS 생존** | **봉인해둔 구간에서 p < 0.05, 부호 유지** ← 핵심 |
| **(D) 비용 통과** | 왕복 0.45% 비용 후에도 buy&hold 초과 (또는 **비용 0인 진입필터로만 사용**) |

**(C)를 통과 못 하면 그걸로 끝이다. 예외 없다.**

> IN Sharpe와 OOS Sharpe의 상관 = **−0.709.**
> 백테스트가 예쁠수록 실전에서 더 나빴다. 이건 측정된 사실이다.

## 문 앞에서 죽은 것들 — 기록으로 남긴다

같은 30년 데이터, 같은 관문. 이걸 기억하지 않으면 같은 실수를 반복한다.

| 가설 | 죽은 관문 | 이유 |
|---|---|---|
| ① 할로윈 (5~10월 약세) | **(B)** | 89개월 중 **6개만 빼면 소멸.** 소수 폭락장 의존 = 알파가 아니라 테일리스크 |
| ② 월초 강세 (TOM) | **(C)** | **IN에서 t=5.49, p=0.0000** 이었다. OOS에서 전멸(p=0.1310) |
| ④ 월중 저점→고점 | (A)(C) | 전 세그먼트 실패 |
| ③ 하순 — **타이밍 규칙**으로 쓰는 안 | **(D)** | 연 24회 왕복 × 0.45% → 우위를 비용이 다 먹는다 (11.81% → 11.89%, 무승부) |

**②를 기억하라.** IN에서 t=5.49면 누구라도 믿는다. 어떤 논문이든 실었을 숫자다.
OOS를 미리 봉인하지 않았다면 오늘 잘못된 규칙을 하나 더 얻었을 것이다.

## 이 폴더의 운영 규칙

1. **채택된 것만 넣는다.** 검정 중인 건 `가상매매\검증\`에 둔다.
2. **근거를 같이 넣는다.** 규칙만 있고 근거가 없으면 1년 뒤에 못 믿는다.
   → `증거\` 에 사전등록서·검정결과·비용관문 원본을 함께 보관.
3. **재판정 날짜를 못 박는다.** 공표된 아노말리는 언젠가 죽는다.
4. **죽으면 기록하고 내보낸다.** `증거\채택기각_로그.csv`에 남기고 여기서 뺀다.
