## 4개 도구

### ④ 선정 vs EW-18 정면 테스트 — `선정_vs_EW_검증.py`
"v3.7.2 초과수익이 종목선정 실력인가, 유니버스+틸트인가?"를 가른다.
```
py 실행키트/선정_vs_EW_검증.py --start 2022-07 --end 2026-06
py 실행키트/선정_vs_EW_검증.py --strategy v37_2_backtest_monthly.csv   # 전략 실현 월수익(열: ym,ret)
```
→ 전략이 EW-18을 IR>0으로 못 넘으면, 사이징·집중도 전략을 EW 기준으로 재설계. (예비 실행: EW-18 CAGR ~51.5% vs 백테 73% → 선정·틸트가 ~20%p 기여, 단 실현 월수익으로 재확인 필요.)

### ③ 매도규칙 v2 (ATR 트레일링) — `매도규칙_v2.py`
`+1R 절반익절` 폐지 + 전 포지션 트레일링(고점−2.5·ATR). "가장 빠른 실제 향상."
```
py 실행키트/매도규칙_v2.py --self-test
py 실행키트/매도규칙_v2.py --replay          # 절반익절 vs 전트레일 기대값 재현
from 매도규칙_v2 import check_exit_v2         # 보유점검/신호등에 배선
```

### ⑦ 사이징·heat·킬스위치 강제 — `사이징_강제.py`
2%룰+ATR · 포트폴리오 heat≤6% · 동시≤5 · 동일테마≤2&≤40% · 킬스위치(일−7/주−12/월−20) · 연속손실 스로틀.
```
py 실행키트/사이징_강제.py --self-test
from 사이징_강제 import size_by_atr, portfolio_heat, killswitch_check
```

### ⑥ 반자동 집행 (KIS 모의) — `execute.py` + `broker/`
엔진 주문안 → **RiskGuard 차단검사 → 사람 승인 → API 집행**. 자동 승인 없음. 모의계좌부터.
```
py 실행키트/execute.py --self-test     # 오프라인 통합(Mock) 검증
py 실행키트/execute.py --demo          # 승인 흐름 시연
# 진우 PC: broker/.kis_key.json 두고(모의계좌) →
py 실행키트/execute.py --broker kis --paper
```
`.kis_key.json` (⚠️ .gitignore 필수):

## 권장 실행 순서 (백서 개선안)
1. `my_holdings.csv`에 진입일 채우기(①, 5분) → 도구·Track W 잠금 해제
2. `매도규칙_v2.py` 배선(③) + `사이징_강제.py` 적용(⑦)
3. `선정_vs_EW_검증.py` 1회 실행(④) → 무기 정체 확인
4. `execute.py --broker kis --paper`로 모의 집행 시작(⑥)
5. 소액 실전 + Track W 측정(②), 레버리지 43→15%·반도체 44→35% 통제(⑤)

## 안전 원칙
- 실거래 API는 **진우 PC 전용**(클라우드 금지). 키/토큰은 로컬 `.kis_key.json`에만.
- 기본은 전부 **모의(paper)**. 실전 전환은 로드맵 §3-2·3-3 통과 후, 코드에서 명시적으로만.
- RiskGuard(집행 직전) + 사이징_강제(전략 규모)는 **별개 방어선** — 함께 쓰세요.
