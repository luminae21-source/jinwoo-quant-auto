# 바닥 주체 + 시장 국면 검증 (KRX 세부수급)

*2026-07 · flow_detail_monthly_*(개인·기타법인·연기금·사모·투신, 2002~, 양시장 수집) + KOSPI 국면 · 신호효능 · 투자자문 아님.*
*질문(진우): 바닥 잡는 주체가 개인인가 세력인가? / 시장 급락과 조정을 나누면?*

## 1. 바닥 잡는 주체 = 진짜 '개인' (세력 아님)
직전 3M 주가국면별 순매수/시총(%), 양수=바닥 받음:
| 유형 | 급락<−20% | 급등>+20% |
|---|---|---|
| **개인** | **+0.595 (받는다)** | +0.003 |
| 연기금 | −0.174 (판다) | +0.042 |
| 투신 | −0.215 (판다) | +0.123 |
| 사모 | −0.101 (판다) | −0.035 |
| **기타법인** | **−0.154 (판다)** | −0.166 |
→ **급락을 받는 건 개인 하나뿐.** 기타법인(자사주·지주·전략적 보유자)·연기금·투신·사모는 모두 하락에 **판다.** "개인 라벨 뒤에 세력이 숨었다" 가설은 **기각** — 진짜 개미가 바닥 유동성을 댄다.

## 2. 어떤 주체든 '사는' 딥밸류는 덜 오른다 (역발상 재확인)
딥밸류바닥 진입월 유형별 순매수>0 vs <0 → 12M:
- 개인 순매수 +54% vs 순매도 +64% (Δ−10p) · 기관 +47 vs +63 · 기타법인 +30.5 vs +69.8
→ **진입 시점 눈에 보이는 매수세가 붙을수록 덜 오른다.** 가장 크게 반등하는 바닥은 **모두가 던지는(아무도 안 사는)** 종목. 순수 역발상일수록 강함.

## 3. "세력이 던지는 딥밸류 강화신호" — 매력적이나 IN/OOS 불안정 → 기각
③ 딥밸류 중 기타법인 던지는 vs 사는(12M 개별): ALL +32.5p(P=0.00)·OOS +37.3p(P=0.00) **강해 보였으나**,
**포트폴리오 CAGR IN/OOS 검증에서 부호가 뒤집힘:**
| | IN CAGR | OOS CAGR |
|---|---|---|
| 딥밸류 전체 | +42.0% | +35.4% |
| 딥+기타법인매도 | **+14.8%** | +46.4% |
| 딥+기타법인매수 | +37.6% | +26.3% |
→ IN에선 기타법인 **매수**가 매도보다 나음(OOS와 정반대). ③의 유의성은 **거의 OOS에만 몰림**(IN P=0.28). §3 양분할 기준 **불통과 → 기각.** (다른 모든 오버레이와 동일: 딥밸류 위에 얹으면 안 됨.)
→ 유일하게 견고한 건 배제규칙: **기관·기타법인이 사고 있는 딥밸류는 피하라**(∩매수 = OOS 열위 반복).

## 4. 시장 급락 vs 조정 — 급락이 골든존 (핵심 신규)
딥밸류 진입 시점 시장국면(직전 3M KOSPI)별 12M (중앙·승률=신뢰지표):
| 시장 국면 | 중앙 | 승률 | n |
|---|---|---|---|
| **시장 급락 <−15%** | **+40.2%** | **79%** | 348 |
| 시장 조정 −15~−5% | −2.1% | 48% | 1113 |
| 시장 보합 | −0.5% | 49% | 2030 |
| 시장 상승 | −5.0% | 46% | 829 |
| 시장 급등 >+15% | +14.6% | 59% | 182 |
- **시장 급락(−15%+)에 산 딥밸류 = 중앙 +40%·승률 79%로 압도적 신뢰.** "피가 흐를 때 사라"가 데이터.
- **어중간한 조정(−5~−15%)은 최악**(중앙 −2%·승 48% = 동전던지기). **급락과 조정은 완전히 다르다.**
- 하락장(중앙 +2.9·승 53%) > 강세장(중앙 −1.8·승 48%) — 신뢰지표 기준. 평균은 강세장·급등이 높으나 소수 대박꼬리.
- **⚠ 한계**: 시장 급락(<−15%, 3M)은 IN(2002·2008·2011)에 집중, OOS엔 거의 없음 → 아래 §5에서 일봉으로 재검증.

## 5. 급락 정밀 재정의(일봉 낙폭·VKOSPI) — "급락 매수"는 OOS 실패 → 기각
월간 3M로는 빠른 급락(2020)을 놓쳐 OOS 표본이 얇았음. 일봉 고점대비 낙폭으로 OOS 급락(2018·2020·2022)까지 포착해 재검증:
| 급락 정의 | IN 중앙/승률 | OOS 중앙/승률 |
|---|---|---|
| 낙폭<−15% | +11% / 57% | **−7% / 38%** |
| 낙폭<−20% | +25% / 66% | **−9% / 35%** |
| VKOSPI>30(2020~) | 데이터없음 | +15% / 75% |
| VKOSPI>35(2020~) | 데이터없음 | +45% / 72% |
- **"시장 급락에 사라"는 IN에만 통하고 OOS엔 실패.** §4의 급락 +40%·승79%는 **IN 급락만 잡힌 착시**. 일봉으로 OOS 급락을 잡으니 중앙 −7~−9%·승 35~38%로 **오히려 나쁨.**
- 원인: 2018·2020·2022 급락 후 회복이 **성장·대형(반도체) 주도** → 얻어맞은 소형 딥밸류는 예전만큼 반등 못 함(엣지 감쇠의 실물).
- 뉘앙스: VKOSPI>35(급성 패닉, 2020) 딥밸류는 +45%·승72%로 좋았음 → **느린 곰장(2022)은 실패, 급성 패닉은 성공**. 단 VKOSPI 2020~라 IN/OOS 검증 불가·표본 36 → **못 믿음.**
- **판정: "시장 급락 타이밍"도 IN-강/OOS-약 → §3 불통과, 기각.** 딥밸류 단독(국면 무조건, OOS +35% CAGR)이 여전히 답. 급락 타이밍 얹지 말 것.
→ §4의 "급락 골든존"은 §5로 **정정(IN 한정 착시)**. 이 재검증은 진우가 "일봉으로 OOS 표본 늘리자"고 제안해 성사됨 — 착시를 정확히 잡아냄.

## 종합
1. 바닥은 개인이 받고(세력 아님), 어떤 주체든 사는 딥밸류는 덜 오른다 → 역발상 재확인.
2. "세력이 던지는 딥밸류" 강화신호는 IN/OOS 불안정 → 기각(딥밸류 단독 유지).
3. **실전 정제: 시장이 급락(−15%+)할 때 딥밸류에 집중.** 어중간한 조정엔 자제. (딥밸류 자체가 본체, 시장 급락은 승률을 크게 높이는 진입 국면.)
