## 3. 왜 통하나 — 시스템 DNA와 일치
- 반도체는 대표적 **경기민감(사이클) 산업.** 수출(업황)이 바닥일 때 주가도 바닥 → 이후 사이클 회복에 크게 반등.
- **"업황 최악에 산다" = "싸고·과매도일 때 산다"(딥밸류)와 동일한 역발상.** 이 시스템이 검증한 엣지의 산업버전.
- 반대로 "호황·성장할 때 산다"(진우 최초 직관, 고점둔화)는 최악 — 퀄리티·성장·수급 오버레이 기각과 정확히 같은 결.

## 4. 실전 함의 + 정직한 경고
