# 종목 선정 스터디 — 생존심사 검증 + 리서치 소스

*2026-07 · 딥밸류 시스템의 실전 종목선정 스터디. 검증 결과 기반. 투자자문 아님.*

## 0. 핵심 원칙 (검증에서 도출)
**종목 선정 = "좋은 회사 고르기"가 아니라 "안 죽을 회사를 분산해 담기".**
퀄리티·성장·수급으로 좁히면 오히려 수익이 깎인다(못난 반등주를 날림). 통계 스크린이 유니버스를 주고, 스터디는 파산만 피하는 역할.

## 1. 생존심사 5기준 — 검증 상태
| 기준 | 상태 | 근거 |
|---|---|---|
| 턴 실체(역배열 밸류트랩 회피) | ✅ 검증됨 | 딥밸류하락장 검증: 트랩군(역배열) 열위, 역배열 금지 |
| 분산 10~15종 | ✅ 검증됨 | 1종 −100% 파산 → 분산이 생존조건 |
| 산업 국면(사이클 바닥) | ✅ 부분검증 | 반도체: 수출 침체국면 진입이 엣지(IN/OOS 유의) |
| **생존력(부채·현금·파산)** | ⚠️ **저가치 판명(예비)** | 아래 §2 |
| 밸류 실체(부실 vs 자산과대) | ❌ 미검증 | 자산구성 데이터(DART) 필요 |

## 2. 솔벤시(파산회피) 필터 — 예비검증: **저가치**
딥밸류바닥 내 EPS 근사로 파산율·수익 분해(2002~2026, 12M):
| 그룹 | 평균 | −100%(파산)율 | +100%(대박)율 |
|---|---|---|---|
| 딥밸류 전체(IN) | +33.1% | **0.7%** | 12.8% |
| 흑자(EPS>0)(IN) | +30.5% | 0.3% | 12.7% |
| 무이익/부실근사(IN) | **+39.0%** | 1.4% | 12.8% |
| 딥밸류 전체(OOS) | +17.5% | **0.0%** | 7.6% |
| 무이익/부실근사(OOS) | **+26.3%** | 0.1% | 11.0% |
- **핵심: 딥밸류바닥 −100% 파산율이 이미 0~1.4%로 극히 낮다.** '턴' 필터가 죽는 종목을 이미 배제 → **솔벤시 필터가 방어할 하방 자체가 거의 없음.**
- **무이익·부실 근사 종목이 오히려 수익↑**(대박율↑) → 솔벤시/퀄리티로 거르면 큰 반등주를 날림.
- → **DART 부채 수집(PC)의 페이오프는 작다.** 생존은 턴 필터+분산으로 이미 처리됨. (진짜 부채발 폭발이 EPS와 다를 여지는 있으나 −100%율 상한이 낮아 개선폭 제한.)
- ⚠️ 한계: KRX EPS는 적자를 음수로 기록 안 함(0/결측). 정밀 솔벤시(부채비율·이자보상배율)는 DART 필요. 단 위 −100%율이 상한을 못박음.

## 3. 리서치 소스 (per-종목 스터디용)
- **★한국IR협의회(KIRS, kirs.or.kr) — 최우선.** 개별기업 리서치보고서 **현재 갱신 중(2026-07)**: 인소싱 1,204건·아웃소싱 1,085건·밸류업 63건·산업분석 165건. 재무현황·밸류에이션·**리스크요인 중립 제공**. 딥밸류 소형주 생존심사에 최적. 밸류업 보고서=주주가치 제고 공시기업(밸류 플레이 참고).
- **KOFIA 코스닥기업분석보고서(kofia.or.kr/brd/m_186)**: 코스닥 종목 브리프 아카이브. **2021까지만 갱신**(과거 공부용·정적).
- **FnGuide 베스트애널리스트(bestanalyst.fnguide.com)**: 애널리스트/리서치 품질 랭킹. 리포트 신뢰도 참고용.
- 활용법: 통계 스크린(타점발굴)이 딥밸류 후보를 주면 → KIRS에서 해당 종목 리스크요인만 확인(파산임박 배제) → 못생겨도 분산 편입.

## 4. 기관 매집 추적 — 모니터링용(엣지 아님)
- 후보별 기관 순매수 추적 뷰는 가능(flow 데이터 보유). 단 **검증상 매수 엣지 아님**(무엣지~음, 호황엔 경계). "돈이 어디 쏠리나" 맥락으로만. 매수 근거로 쓰지 말 것.

## 5. 결론 — 종목 선정 실전 절차 (검증 반영)
1. **스크린(검증 엣지):** 저PBR(하위20%)∩이격<0.85∩턴(20일>0). 즉시 매수(눌림 대기 금지·엔트리검증).
2. **per-종목 스터디 = 파산 배제만:** KIRS 리서치로 역배열·계속기업 리스크 확인. **퀄리티 업그레이드 금지**(고ROE·성장 선호 = 역효과).
3. **분산 10~15종:** 못난 종목 포함해 담기(우측 대박꼬리). 1종 집중 금지.
4. **산업국면:** 경기민감(반도체 등)은 업황 침체국면이 진입점, 호황 고점 자제.
5. **매도:** 강함에 익절(이격≥1.5 or +100% or PBR≥1.0). 스톱 아닌 분산·소액으로 리스크.

---
*요약: 종목 선정의 스터디는 '좋은 회사 찾기'가 아니라 'KIRS로 파산임박만 배제하고 분산'이다. 딥밸류 바닥은 파산율이 이미 낮아(턴 필터) 솔벤시 필터의 가치가 작다. 리서치는 KIRS(현행)가 최적, KOFIA는 과거 아카이브.*
