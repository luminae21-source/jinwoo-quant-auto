# 진우퀀트 — Forward 동결 사양서 v1 (사전등록·수정금지)

> **목적:** 백테스트 연구를 끝내고 **전략을 동결한 뒤 소액/페이퍼 forward(달력 시간)로 검증**한다. 이것이 유일하게 남은 관문 — 시장만이 심판할 수 있는 부분.
> **핵심 규율(PBO 57% 교훈):** "인샘플 최고 설정"을 고르지 않는다. 아래는 **사전등록 고정값**이며, 수정금지기간 동안 결과를 보고 바꾸지 않는다.
> **동결일:** 2026-07-27 · **작성:** 진우퀀트 · ⚠️ 정보·검증용 · 투자자문 아님.

---

## 0. 이 문서가 명시적으로 포기하는 것

- ❌ "연 20.1% / Sharpe 0.85" — 재현 실패로 폐기. **기대수익으로 쓰지 않는다.**
- ❌ 트레일링 스톱(−25% 등) — 재보정 결과 수익/낙폭 비율이 무스톱보다 나빠 **채택 안 함.**
- ❌ "인샘플 최고 파라미터"(배당단독·N20 등) 고르기 — PBO 57%라 과최적. **사전등록 규칙만 쓴다.**

## 1. 유니버스 (동결)

| 항목 | 고정값 |
|---|---|
| 시장 | KOSPI (1차). KOSDAQ은 조정본 caveat 해소 후 별도 편입 검토 |
| 후보 | 매월 말 시가총액 상위 **300종목**(대형·유동 '주도주'급) |
| 최소 거래대금 | 최근 20거래일 평균 ≥ 20억원 |
| 상장 후 최소 기간 | 12개월 |
| 제외 | 관리종목·거래정지·정리매매·감사의견 비적정 · 우선주 · 지주 스팩 · 최근 CA(무증/유증/분할) 진행 중 |
| 재무 결측 | 팩터 계산 불가 종목은 해당 월 제외(임의 대체 금지) |

## 2. 팩터·선정 규칙 (동결)

- **합성점수 = 등가중 z( 배당수익률 div, B/P, E/P, ROE )** — 검증 통과 팩터만. 성장(EPS성장 g1)은 유의미달로 **제외**.
- 매월 말 횡단면 z-score 계산 → 합성점수 **상위 30종목**, **동일가중**.
- 동점 처리: 시가총액 큰 순.
- ⚠️ **가중치·N·팩터 구성은 수정금지기간 동안 고정.** (PBO 교훈: 최적화 유혹 차단)
- **병행 관찰(별도 기록, 실전배분 아님):** '배당단독 top30' — 격자 최고였던 단순 규칙. 실전엔 안 쓰되 forward IC를 같이 기록해 사후 비교.

## 3. 리밸런싱·매도 (동결)

| 항목 | 고정값 |
|---|---|
| 주기 | 월 1회, 매월 첫 거래일 종가 기준 신호 → 익일 시가 체결 |
| 교체 | 상위30 이탈 종목 매도, 신규 진입 매수 |
| 스톱 | **트레일링/재난 스톱 없음.** 낙폭 통제는 아래 현금방어·사이징으로 |
| 방어 | KOSPI지수 < 10개월 이동평균이면 **현금비중 50%**(신규 진입 절반 축소) |
| 종목 사이징 | 동일가중, 1종목 최대 비중 상한 6% |

## 4. 비용 모델 (동결·수익에서 차감)

- 매수 15bp + 매도 33bp(거래세 0.20% 포함) = **왕복 약 0.48%** + 슬리피지 버퍼 월 회전율×0.1%.
- forward에서는 **실제 체결가**로 재계산하고 모델가와 차이를 기록.

## 5. 기대치 (정직한 사전 선언)

- **기대수익:** 팩터 프리미엄 수준 = 연 **3~6%p 초과수익 가능성**(비용후), 단 **성장 주도장에선 지수에 뒤질 수 있음**(2015~2026이 그 예). 20%대 아님.
- **기대 MDD:** −35% 이상 각오(2008 미포함 백테라 실제는 더 나쁠 수 있음).
- **성공의 정의 ≠ 매 구간 KOSPI 초과.** 성공 = 아래 6장 게이트 통과.

## 6. 평가 게이트 (사전등록·수정금지기간 종료 후 판정)

**수정금지기간: 최소 6개월(권장 12개월).** 이 기간 파라미터 변경 금지. 종료 후 아래로 판정:

| 지표 | 성공 기준 | 실패 기준 |
|---|---|---|
| Forward 팩터 IC | 평균 > 0, 부호가 백테와 일치 | 지속적 음(−) |
| 예상신호 vs 실제신호 | 월별 종목 일치율 ≥ 95% | 잦은 불일치(버그) |
| 체결가 vs 모델가 | 평균 슬리피지 ≤ 가정치 | 초과 |
| 회전율 | 백테 가정 ±20% 이내 | 크게 초과 |
| 규칙 위반 | 0건 | 임의 개입 발생 |

- **판정 3분기:** 성공(계속·증액 검토) / 보류(1기간 연장) / 폐기(엣지 없음 확정).
- ⚠️ **기간 중 성과가 나빠도 파라미터를 바꾸지 않는다.** 나쁜 결과도 데이터. 실패는 자존심이 아니라 정보.

## 7. 기록 의무 (매 리밸런싱)

매월 저장: 신호 생성 원본(팩터값·z·점수·선정명단) · 실제 체결가·시각 · 현금비중 · 회전율 · 비용 · 이탈/진입 사유. → 재현 가능한 원장(ledger)으로 누적.

## 8. 실행 경계 (안전)

- 실계좌 집행(KIS)은 **PC에서 사용자 본인이** 최종 확인 후 실행. 자동주문 전 리스크차단기(과집중·현금초과·주문오류) 통과 필수.
- 최초는 **페이퍼 또는 극소액**으로 시작. 게이트 통과 전 증액 금지.
