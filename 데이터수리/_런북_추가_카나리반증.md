### ⛔ 배포 2차 — 실패한 것은 KIS가 아니라 내 카나리였다 (2026-07-28, PC 2회차 실행)

셀프테스트는 **21/21 PASS**, 접착부 버그는 실제로 고쳐졌습니다. 그런데 `--canary` 가 이렇게 나왔습니다.

```
005930(KOSPI)  2018-04  수정주가 ok: 52,999 (기대 53,000)   원주가 ok: 2,650,000 (기대 2,650,000)
064550(KOSDAQ) 2018-04  수정주가 ok: 12,750 (기대 12,750)   원주가 mismatch: 12,750 (기대 51,000)
판정: ✗ 실패 — 조정가가 아니거나 오염
→ 카나리가 통과하지 않았습니다. 본수집을 시작하지 않습니다.
```

**여기서 절대 하지 말아야 할 일이 기대값을 12,750으로 바꾸는 것입니다.** 그건 카나리를 없애는 짓입니다.
그래서 기대값 51,000이 **어디서 나온 숫자인지**부터 되짚었습니다.

**결론: 51,000은 어느 패널에서도 관측된 적이 없는, 내가 계산해서 넣은 값입니다.**
`ca_flags.csv` 의 064550 ×2 두 건(2021-08, 2023-02)을 곱해 `12,750 × 4 = 51,000` 으로 만든 숫자였습니다.
그리고 그 두 건 중 **2021-08은 기업행위가 아니었습니다.**

| 검증 | 방법 | 결과 |
|---|---|---|
| 064550 2018-04-30 실거래 종가 | `종목일봉_30년_KOSDAQ.csv`(by-date 수집) | **12,750** — 51,000은 없음 |
| 064550 2021-08 ×2.043 | 일봉 일별 추이 | 35,000 → 74,000 **점진 상승** = 단순 랠리, **오탐** |
| 064550 2023-02 ×2.011 | 일봉 | 2023-02 **거래 0행**(거래정지) 후 ~2배 재개 = 실제 기업행위 가능성 |
| 098460 2025-01 ×2.016 | 일봉 + pykrx 수정주가 | 단일일 불연속 없음 → **오탐** (아래에서 재확인) |

`ca_flags.csv` 의 판정 근거인 `is_ca(ratio)` 는 **월 비율이 정수 R의 ±3% 안이면 기업행위로 찍습니다.**
그래서 한 달에 정직하게 +100% 오른 종목이 전부 "감자/병합"으로 기록됩니다. 위 두 건이 그 증거입니다.
(`ca_adjust.py` 를 상장주식수 = 시총 ÷ 종가 근거로 갈아엎어야 하는 이유가 이제 추정이 아니라 실측입니다.)

**교체한 카나리 셀 — 계산이 아니라 세 곳에서 실측한 값만 씁니다.**

098460(고영) 2021-04-13 5:1 액면분할. 2018-04 값:

| 출처 | 값 |
|---|---|
| `종목일봉_30년_KOSDAQ.csv` 2018-04-30 | 101,800 |
| `데이터수리/_월봉종가캐시_KOSDAQ_full.csv` 2018-04 | 101,800 |
| 운영 캐시 `_월봉종가캐시_KOSDAQ.csv` 2018-04 | 101,800 |
| `데이터수리/_월봉종가캐시_KOSDAQ_adj.csv` 2018-04 (pykrx 수정주가) | 20,360 |

```python
("098460", "KOSDAQ", 2018, 2018, "2018-04", 20_360, 101_800)   # 5:1 (2021-04-13)
```

101,800 ÷ 20,360 = **정확히 5.0**. 부수 소득이 하나 있습니다 — 만약 `ca_flags` 의 098460 2025-01 ×2가
진짜였다면 pykrx 수정주가는 배수 10을 반영해 10,180 이어야 합니다. **5.0으로 나온다는 것 자체가
그 항목이 오탐이라는 독립 증거입니다.**

**새 원칙(박제): raw == adj 인 셀은 카나리가 아니다.** 판별력이 0이면 미조정 패널이 그대로 통과합니다.
구조적으로 막기 위해 테스트를 추가했습니다.

```
㉒ 카나리 셀 판별력 (raw/adj ≥ 1.5): 005930×50.0 · 098460×5.0
```

→ **셀프테스트 22/22 PASS**. 음성대조 확인: raw==adj 셀을 되돌리면 ㉒가 **FAIL**(21/22)로 뜨며
`005930×50.0 · 064550×1.0` 을 찍습니다.

**같은 오염이 운영 코드에도 있었습니다 — 실동작 구멍.**
`ca_guard.py` 의 `ADJ_CANARY` 도 064550 / 51,000을 쓰고 있었고, `assert_adjusted()` 는 `v >= max_close`
하나만 봅니다. raw == adj == 12,750, `max_close: 25,000` 이므로 **미조정 KOSDAQ 패널이 "조정됨"으로
통과하는 위음성**이었습니다. 098460 셀로 교체하고(백업 `ca_guard.py.bak_0728_카나리교체`) 확인:

```
KOSPI : 005930  판별력 x50.0 · 임계가 두 값 사이? True
KOSDAQ: 098460  판별력 x5.0  · 임계가 두 값 사이? True
```

폐기 사유는 기존 주석을 **지우지 않고 덧붙였습니다**.
